# WanderWise ✈️ — Travel, Wisely

A single-page travel planning web app built with HTML, CSS and vanilla JavaScript.
Explore destinations, plan a trip around your budget, and keep a travel journal of your memories.

## Features
- **Authentication screens:** sign up, log in, and password reset flow
- **Destination explorer:** popular destinations, a Karnataka spotlight, city search, best time to visit, quick guides and packing suggestions
- **Trip budget planner:** estimate trip costs based on your budget
- **Travel journal:** add entries with photos, view and delete memories
- **Profile page:** recent journal activity and preferences

## Tech Stack
- HTML5, CSS3 (custom properties, responsive layout)
- Vanilla JavaScript (state-driven rendering, no frameworks)
- Google Fonts (Fraunces, Inter)

## Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/ritika150506-cell/wanderwise.git
   ```
2. Open `index.html` in your browser. No build step or dependencies needed.
